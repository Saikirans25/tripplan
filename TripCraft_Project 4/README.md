# TripCraft Premium Dashboard

A premium travel dashboard concept inspired by the uploaded reference's airy glassmorphism, travel photo cards, timeline calendar, memory stack, and map footprint. It uses its own TripCraft identity and content.

## Run it
1. Extract the ZIP.
2. Open `TripCraft_Project/index.html` in Chrome or another modern browser.
3. Internet is needed for Google Fonts and remote scenic backgrounds. Local destination images are bundled in `assets/`.

## Interactions
- Sticky translucent navigation with active-section highlighting
- Animated profile card, timeline trips, and destination cards
- Clickable calendar trip pills and trip details modal
- Interactive previous-memory stack and shuffle button
- Map zoom controls, animated travel route, and animated statistics
- Quick destination chips and trip idea form
- Responsive mobile navigation and scroll-triggered entrance animations

## Notes
This is a front-end prototype. The world map is a stylized illustration, and trip, country, budget, and itinerary details are demo content. It does not connect to real travel booking, live maps, or user accounts.
